🚀 Then vs Now
We use "used to" for habits and situations that were true in the past — but not any more.
⏮️ Then (past)
I used to walk to school.
▶️ Now
But now I take the bus.
«used to» تصف عادةً أو حالةً كانت صحيحة في الماضي وتوقّفت. المعنى: كان يفعل… لكنه لم يعد يفعل الآن. لنكتشف الشكل!

📌 The Three Forms — at a Glance
ملخّص الأشكال الثلاثة قبل الاكتشاف.
➕ Positive
I used to + base  →  She used to live in Gaza.
➖ Negative
I didn't use to + base  →  He didn't use to like tea.
❓ Question
Did … use to + base?  →  Did you use to play football?
🔍 What Changed?
Compare "then" and "now". What form follows "used to"?
قارن الماضي بالحاضر. ما الفعل الذي يأتي بعد used to؟ وهل يتغيّر مع الضمائر؟
Then
She used to have [used to + base] long hair.
Now
Now she has short hair.
Then
They used to live in a village.
Now
Now they live in the city.
💡 Notice: the verb after used to is always the base form (no -s, no -ed) — and it's the same for I, you, he, she, we, they.

⭐ The Pattern

➕ used to + base  ·  ➖ didn't use to + base  ·  ❓ Did … use to + base?

🧠 The Full Rule
القاعدة الكاملة لـ used to مع الأمثلة.
➕ used to + base verb
➖ didn't use to + base verb
❓ Did + subject + use to + base verb?
I used to be afraid of the dark. (a past state)
We used to play in the street every evening. (a past habit)
Did you use to collect stamps?
🧠 Important Notes
⚠️ After did/didn't → use to (drop the -d):
✗ Did you used to…  |  ✓ Did you use to…
✗ I didn't used to…  |  ✓ I didn't use to… بعد did/didn't نحذف الـ d فتصبح use to.
✅ Same for all subjects — no -s, no -ed on the main verb:
I / you / he / she / we / they used to go. الشكل نفسه مع كل الضمائر، والفعل يبقى مجرّدًا.
💡 used to (past habit) ≠ be used to (accustomed):
"I used to live here." (past)  ·  "I am used to the noise." (I'm accustomed to it now) used to = عادة ماضية، أمّا be used to = معتاد على (الآن).

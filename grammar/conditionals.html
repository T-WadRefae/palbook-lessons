Conditionals 🌠

الجمل الشرطية — Types 0 · 1 · 2

🎯 Grades 8 & 9 ⏱️ ~40 min 🌠 If… Then…
🚀 What Would You Do If…?
We use "if" to talk about conditions and results — every day!
🔵 Always True (Fact)
If you heat ice, it melts.
🟢 Real Possibility (Future)
If it rains tomorrow, I will stay home.
🟣 Imaginary / Dream
If I were a bird, I would fly to Jerusalem.
ثلاثة أنواع من الجمل الشرطية — كل نوع لموقف مختلف: حقيقة علمية، احتمال حقيقي، أو حلم خيالي. لنكتشف!

📌 Three Types at a Glance
ملخص الأنواع الثلاثة — للمراجعة السريعة قبل اكتشاف القاعدة.
🔵 Zero (Type 0)
Scientific Facts & General Truths
الحقائق العلمية والحقيقة الدائمة
If + Present → Present
"If you mix red and blue, you get purple."
🟢 First (Type 1)
Real & Likely Future
الاحتمال الحقيقي المستقبلي
If + Present → will + base
"If it rains, I will take an umbrella."
🟣 Second (Type 2)
Imaginary / Unlikely
الافتراضي والخيالي
If + Past → would + base
"If I had wings, I would fly to Mecca."
🔍 Compare the Three Types!
Look carefully at the verbs in the if-clause and the main clause.
قارن الأفعال في كل نوع. ما الفرق بين الأزمنة المستخدمة في كل جملة؟
TYPE 0 — General truth
If you heat [Present] ice, it melts [Present].
Both verbs are Present Simple.
TYPE 1 — Likely future
If it rains [Present] tomorrow, I will take [will + base] an umbrella.
If-clause: Present Simple → Main clause: will + verb.
TYPE 2 — Imaginary
If I had [Past Simple] wings, I would fly [would + base] over Palestine.
If-clause: Past Simple → Main clause: would + verb.
💡 Key Trick — Type 2: Use were (not was) for ALL subjects:
If I were rich… / If he were here… / If she were a teacher…

⭐ The Pattern

🔵 Type 0: If + present → present
🟢 Type 1: If + present → will + base
🟣 Type 2: If + past → would + base

🧠 All Three Types — Full Rules
القواعد الكاملة للأنواع الثلاثة مع الأمثلة.
🔵 Type 0
Zero Conditional
الحقائق العلمية والعامة
If + Present Simple,
Present Simple
If you freeze water, it becomes ice.
If plants don't get water, they die.
🟢 Type 1
First Conditional
الاحتمال الحقيقي المستقبلي
If + Present Simple,
will + base verb
If it rains, I will stay home.
If you work hard, you will succeed.
🟣 Type 2
Second Conditional
الافتراضي والخيالي
If + Past Simple,
would + base verb
If I were the president, I would build more schools.
If she had a car, she would drive to work.
🧠 Important Notes
⚠️ Type 2 — always use WERE:
✗ If I was rich…  |  ✓ If I were rich…
✗ If he was here…  |  ✓ If he were here…
(were تُستخدم مع جميع الضمائر في الشرطي الثاني)
✅ If-clause position: The if-clause can come first OR second.
First: "If it rains, I will stay home." — comma needed
Second: "I will stay home if it rains." — no comma
💡 Unless = if… not:
"Unless you study, you won't pass." = "If you don't study, you won't pass."
unless = إلا إذا / ما لم

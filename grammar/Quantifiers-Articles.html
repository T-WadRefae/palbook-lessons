Some & Any

متى نستخدم some و any؟

🧺

The Rules

1
Use some in affirmative (Yes) sentences — with uncountable nouns & plural countable nouns.استخدم some في الجمل المثبتة — مع الأسماء غير المعدودة والجمع
2
Use any in negative (No) sentences — same noun types.استخدم any في الجمل المنفية
3
Use any in Yes/No questions — same noun types.استخدم any في الأسئلة
4
With singular countable nouns, use a / an instead.مع الأسماء المعدودة المفردة استخدم a / an
Type Word Example
✅ Affirmative some There are some tomatoes. / There is some tomato paste.
❌ Negative any There are not any tomatoes. / There is not any tomato paste.
❓ Question any Are there any tomatoes? / Is there any tomato paste?
A: Are there any burgers?  →  B: No, there aren't any burgers, but there are some kebabs.
2

Much & Many

متى نستخدم much و many؟

⚖️

The Rules

1
Use many with countable nouns (things you can count).many مع الأسماء المعدودة
2
Use much with uncountable nouns (things you can't count).much مع الأسماء غير المعدودة
3
Ask: How many … are there?  /  How much … is there?للسؤال عن الكمية
4
Often used in negative statements: There aren't many / There isn't much.كثيراً ما تُستخدم في النفي
Word Noun Type Example
many Countable ✔ How many olives are there? — There aren't many.
much Uncountable ✗ How much olive oil is there? — There isn't much.
Shopping list example: We haven't got many kebabs, and we haven't got much ground meat.
3

Articles: a / an / the

أدوات التعريف والتنكير

📌

The Rules

1
Use a / an when you first mention something new — the listener doesn't know it yet.a / an عند ذكر الشيء لأول مرة
2
Use the when both speaker & listener know which specific thing you mean.the عندما يعرف المتحدث والمستمع ما يُقصد
3
Use no article (Ø) when talking about all things of a type (general meaning).بدون أداة عند الحديث عن أشياء بشكل عام
Article When to use Example
a / an First mention (new info) Kuwait is a desert country. / Perhaps you had some bread.
the Known / specific reference The climate there is hot. / The wheat was probably American.
Ø (nothing) General / all of a type Ø Olive trees grow slowly. / People use Ø wheat to make bread.
Story flow: Kuwait is a desert country. The climate there is hot and dry. The climate is bad for Ø olive trees.

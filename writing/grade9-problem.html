📌 Lesson Objectives

في نهاية الدرس، سيكون الطالب قادراً على: ✍️

  • 1State a problem (environmental or social) clearly.
  • 2Explain why the problem is serious.
  • 3Suggest solutions using clear phrases.
  • 4Support each solution with a reason.

💡 A Model Paragraph

اقرأ الفقرة (المشكلة بالأحمر، الحلول بالأخضر، الأسباب بالأصفر)، ثم اضغط على كل جزء 👇.

Water is wasted in many homes. This is a serious problem because water is precious in Palestine. One solution is to fix leaking taps. Another solution is to collect rainwater. These ideas would help because they save water for farms and families. If we act now, we will have enough water for everyone.
▶⚠️ State the problem
Begin by naming the problem clearly: "… is a serious problem."

ابدأ بعرض المشكلة بوضوح في جملة الموضوع: Water is wasted… / Pollution is a serious problem.

▶📉 Why is it serious?
Give the effect: This is serious because…

اشرح لماذا المشكلة مهمّة وما آثارها: This is a serious problem because …

▶💡 Suggest solutions
Use: One solution is to… / Another solution is to… / We could…

اقترح حلولاً بعبارات واضحة: One solution is to… / Another solution is to… / We could…

▶🧩 Support & conclude
Add a reason (because/so) and a strong closing (If we…, we will…).

ادعم كل حلّ بسبب (because / so)، واختم بجملة مقنعة: If we act now, we will…

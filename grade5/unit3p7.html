🎯 Lesson Objectives · أهداف الدرس

To write the ordinal words (9th → ninth).
أن أكتبَ الأعدادَ الترتيبية كلماتٍ (9th → ninth).
To write correct sentences with a CAPITAL letter and a full stop.
أن أكتبَ جملًا صحيحةً تبدأ بحرفٍ كبيرٍ وتنتهي بنقطة.
To think and write sentences about races.
أن أُفكِّرَ وأكتبَ جملًا عن السباقات.
To practise handwriting: first … twelfth · minute · metre.
أن أتدرّبَ على الخطّ: first … twelfth · minute · metre.

✍️ Sentence Builder

Name + is + ordinal + in the + race.
Name + can + verb + distance + in/for + time.
مثال: I'm second in the swimming race. · I can swim 100 metres in 2 minutes.

✏️ Write Correct Sentences

💡

Remember, use a CAPITAL letter at the start of a sentence. Use a full stop (.) at the end of a sentence.

✍️ رتِّب الكلماتِ واكتب الجملةَ الصحيحةَ في دفترك، ثم اضغط «Answer» للتحقق.
الجمل ١–٤: Name + is + الترتيب + in the + السباق · الجمل ٥–٦: Name + can + الفعل + المسافة + in/for + الزمن

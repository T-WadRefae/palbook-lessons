✏️

Verb forms

📘 First conditional

If + present simple, … will / won’t + verb

If you talk, perhaps he’ll understand. = Perhaps he’ll understand if you talk.

نستعملُها لشيءٍ قد يحدثُ في المستقبل: جزءُ if بالمضارعِ البسيط، والنتيجةُ بـ will. وإذا بدأنا بـ if نضعُ فاصلة.
